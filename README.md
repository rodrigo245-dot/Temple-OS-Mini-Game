## 💻 Téléchargement & Exécution

### 🍎 macOS (macOS 10.15+)
- **Installateur officiel :** Téléchargez [`TempleOS_Arcade.dmg`](TempleOS_Arcade.dmg), ouvrez-le et glissez l'icône dans **Applications**.
- **Archive ZIP :** [`TempleOS_Arcade_Mac.zip`](TempleOS_Arcade_Mac.zip)

### 🪟 Windows (Windows 10 / Windows 11 x64)
- **Application autonome :** Téléchargez [`TempleOS_Arcade_Windows_x64.zip`](TempleOS_Arcade_Windows_x64.zip).
- Décompressez l'archive et double-cliquez sur **`TempleOS_Arcade.exe`**.
- *(Utilise le moteur natif Microsoft Edge WebView2 déjà intégré à Windows 11).*

### 🌐 Version Web Autonome
Ouvrez simplement [`index.html`](index.html) dans n'importe quel navigateur Web moderne (Chrome, Safari, Firefox, Edge).
